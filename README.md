# Manas Thikekar — Modern Engineering Portfolio

An award-winning, editorial single-page portfolio crafted with **React, TypeScript, Tailwind CSS, Framer Motion, and Lenis**. Designed with premium dark aesthetics, subtle glassmorphism, high-frame-rate particle canvas, and interactive micro-interactions.

---

## 🌟 Key Features

1. **Section 01 — Navigation**: Glassmorphic floating navigation bar, monogram brand badge (`MT`), scroll spy active section tracking, smooth anchor scrolling, and a mobile responsive menu drawer.
2. **Section 02 — Hero Section**:
   - Live status indicator with glowing pulse (`Available for Engineering Roles`)
   - Interactive 60 FPS HTML5 Canvas particle constellation that responds to mouse velocity and proximity
   - Oversized typography with staggered character reveals
   - Magnetic action buttons ("View Featured Projects", "Contact Me", "Resume")
   - Floating technical telemetry cards
3. **Section 03 — Storytelling About Me**:
   - Narrative editorial layout
   - Live TypeScript developer profile terminal (`engineer_profile.ts`)
   - Core value cards with visual depth
   - Key impact metrics (350+ DSA problems solved, production projects)
4. **Section 04 — Technical Arsenal & Skills**:
   - Organized into 6 distinct categories: Programming Languages, Frontend, Backend, Databases, Tools & DevOps, and Competitive Programming & DSA
   - Honest, descriptive badges (e.g. `Strict Type Safety`, `Core DSA`, `ACID Transactions`) instead of arbitrary percentages
   - Interactive category filter tabs
5. **Section 05 — Trajectory (Experience & Education Timeline)**:
   - Interactive vertical timeline with glowing nodes
   - Filter between Academics, Milestones, and Training
   - Technology tags, key bullet points, and organizational context
6. **Section 06 — Craft & Code (Featured Projects)**:
   - High-density visual showcase cards with mock browser chrome
   - Granular breakdown of **Problem Solved** and **My Engineering Contribution**
   - Verified GitHub repository and live preview triggers
   - Metric pills highlighting latency and performance
7. **Section 07 — Honors & Recognition**:
   - Hackathon finalist, competitive programming milestones, certifications, and academic honors
   - Category badges with gold, cyan, and violet highlights
8. **Section 08 — Radar & Horizons (Currently Exploring)**:
   - Futuristic radar telemetry grid
   - Ongoing exploration areas: Distributed Systems, ICPC DSA, AI Agents, and WebGL/Shaders
   - Depth progress bars and technology tags
9. **Section 09 — Initiate Transmission (Contact & Footer)**:
   - One-click copy email button with instant feedback
   - Verified profile links (GitHub, LinkedIn, LeetCode, Codeforces, X)
   - Interactive contact form with confetti celebration trigger
   - Live Indian Standard Time (IST) clock
   - Smooth back-to-top scroll button

## ⚡ Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Build for production
npm run build

# 4. Preview production build locally
npm run preview
```

## 🛠️ How to Update Your Personal Information

All information across the entire website is centralized in **one single file**:
`src/data/portfolioData.ts`

To update your email, resume link, social URLs, projects, or achievements, simply edit `src/data/portfolioData.ts`. No component code changes are required!
